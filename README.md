# Typora Theme

基于 [Claude Typora Theme](https://theme.typora.io/theme/Claude/) 定制的 Typora Markdown 主题。:contentReference[oaicite:0]{index=0}

## 简介

本主题基于 Claude 风格 Typora 主题进行二次定制，针对 Markdown 写作场景进行优化，适用于：

## 特性

- 保留 Claude 风格的简洁、舒适阅读体验
- 优化中文 Markdown 排版
- 根据我的个人习惯优化了表格和代码块。

## 使用方式

1. 下载主题文件
2. 将 CSS 文件放入 Typora 主题目录
3. 重启 Typora
4. 在：ypora → 偏好设置 → 外观 → 主题中选择该主题
